## What it does
Lists untagged Paperless documents, asks the LiteLLM gateway LLM (glm-5.3-flash) for a German
classification (tags, korrespondent, typ, zusammenfassung) and writes the suggested tags back
via the Paperless REST API (get-or-create tags). Idempotent via scripts/.paperless-classify.state.json.

## One-time setup
1. Create a superuser in Paperless (or use an existing admin).
2. Generate a DRF token: `docker exec opensme-paperless python3 manage.py drf_create_token <user>`
   (captured into .env as PAPERLESS_API_TOKEN — value never printed).
3. Ensure LITELLM_MASTER_KEY (or LITELLM_API_KEY) is available in the environment so the
   script can authenticate to the local gateway (host-reachable after port publish 127.0.0.1:4000:4000).

## Operational notes
- Gateway is host-reachable on 127.0.0.1:4000 (services/litellm.yml publishes the port, localhost-only, authenticated).
- Script runs on host or in-container (stdlib only). Use LITELLM_BASE=http://litellm:4000/v1 when running in-container.
- State file gitignored: scripts/.paperless-classify.state.json.
- Optional hook: call `paperless-classify.py classify <id> --apply` from paperless-intake.sh after ingest.
