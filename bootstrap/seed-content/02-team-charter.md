# Team Working Agreement

A short charter a team can agree on when it starts working in openSME.
Edit it to fit, then store a copy in **Cloud → Team** so everyone can read it.

## How we work

- **One account.** We sign in only through *Identity*; no per-service
  passwords on sticky notes.
- **Cloud is the source of truth** for shared files. Never email a document
  around — put it in the **Cloud → Team** folder and link to it.
- **Open in place.** When a document or spreadsheet needs editing, open it
  with **Office** from the Cloud instead of downloading a local copy.
- **Workflow over email chasing.** Requests that repeat (approvals, leave,
  procurement) run as **Workflow** processes, not as email threads.

## Our shared folders in the Cloud

- `Team/Charter` — governance and decisions
- `Team/Operations` — runbooks and on-call notes
- `Team/Projects` — one folder per active project
- `Inbox` — anything that still needs a home

## Meetings & notes

- Calendar lives in **Webmail**; keep team events there.
- Meeting notes are short **Team Notes** in the Portal (with a link to the
  Cloud file), never long email summaries.

## If something breaks

- Raise a ticket on **Support** (it feeds the knowledge base).
- Check the operator runbooks in `opensme-knowledge/` before escalating.
- The Workflow engine has an **approval** process you can reuse for
  change requests — start it from the **Workflow** service.
